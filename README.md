# Эмулятор UNIX-оболочки

Кроссплатформенный эмулятор командной строки на C++17. Реализованы этапы 1–3 варианта 8: REPL, параметры запуска и виртуальная файловая система (VFS) на основе ZIP.

## Сборка

Нужны CMake 3.16+, компилятор C++17 и zlib.

```sh
cmake -S . -B build
cmake --build build
```

## Запуск

```sh
./build/emulator --vfs build/vfs/minimal.zip
./build/emulator --vfs build/vfs/nested.zip --script scripts/stage3/full_demo.emu
```

`--vfs` задаёт ZIP-архив, `--script` — стартовый скрипт. Алиасы: `--vfs-path` и `--startup-script`. Строки скрипта показываются как ввод; комментарии начинаются с `//`. В интерактивном режиме после скрипта появляется приглашение оболочки.

## Команды

| Команда | Действие |
|---|---|
| `ls`, `cd` | Заглушки этапа 1 |
| `echo` | Вывод текста с подстановкой переменных окружения |
| `regvar ИМЯ ЗНАЧЕНИЕ` | Установка переменной окружения процесса |
| `vfs-save ПУТЬ` | Сохранение VFS в ZIP-архив |
| `exit` | Выход |

VFS работает в памяти и не распаковывает файлы на диск. Поддерживаются ZIP Store и Deflate; ZIP64, многотомные и зашифрованные архивы не поддерживаются. ZIP-примеры автоматически создаются из C++ при сборке в `build/vfs/`: минимальный, с несколькими файлами и с вложенными каталогами. Архивы в Git не хранятся.

## Примеры запуска

```sh
bash scripts/stage2/run_minimal.sh
bash scripts/stage2/run_nested.sh
bash scripts/stage3/run_all.sh
```
