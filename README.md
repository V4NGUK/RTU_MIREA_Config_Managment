# C++ UNIX-like Shell Emulator

Кроссплатформенный эмулятор UNIX-like командной строки для ОС Windows / Linux / macOS, поддерживающий определенный перечень команд, выполняющихся в среде реальной ОС.

## Возможности

- Выполнение команд, взаимодействующих с реальной ОС
- Разрешение переменных окружения

## Текущий список команд

| Команда | Описание | Пример |
| ------- | -------- | ------ |
| `cd`    | Смена рабочей директории (в настоящий момент заглушка) | `cd /dev/null` |
| `ls`   | Вывод списка файлов текущей директории (в настоящий момент заглушка) | `ls` |
| `exit` | Выход из программы | `exit` |
| `echo`  | Вывод строки в консоль | `echo $PATH` |
| `regvar` | Создание переменной окружения (для текущего процесса) | `regvar TEST_HOME /home/test` |

## Требования

Для сборки и запуска программы требуются:
- Компилятор с поддержкой стандарта **C++17** (`g++`, `clang` или MSVC).
- Система автоматизации сборки **CMake** (версии 3.16 или выше).
