# Эмулятор UNIX-оболочки

Кроссплатформенный эмулятор на C++17. Реализованы этапы 1–5 варианта 8; файлы VFS хранятся в памяти.

## Сборка

Нужны CMake 3.16+, компилятор C++17 и zlib.

```sh
cmake -S . -B build
cmake --build build
```

## Запуск

```sh
./build/emulator --vfs build/vfs/minimal.zip
./build/emulator --vfs build/vfs/commands.zip --script scripts/stage4/full_demo.emu
```

`--vfs` задаёт ZIP-архив, `--script` — стартовый скрипт. Алиасы: `--vfs-path` и `--startup-script`. Строки скрипта показываются как ввод; комментарии начинаются с `//`. В интерактивном режиме после скрипта появляется приглашение оболочки.

## Команды

| Команда | Действие |
|---|---|
| `ls [-al] [ПУТЬ...]` | Список файлов; `-a` — скрытые имена, `-l` — права, размер и время UTC |
| `cd [ПУТЬ\|-]` | Смена каталога; без аргумента — корень, `-` — предыдущий каталог |
| `tac [ФАЙЛ...]` | Вывод строк в обратном порядке |
| `rev [ФАЙЛ...]` | Разворот символов UTF-8 в каждой строке |
| `echo` | Вывод текста с подстановкой переменных окружения |
| `regvar ИМЯ ЗНАЧЕНИЕ` | Установка переменной окружения процесса |
| `vfs-save ПУТЬ` | Сохранение VFS в ZIP-архив |
| `vfs-load ПУТЬ` | Загрузка другого ZIP; при успехе текущий каталог становится `/` |
| `chmod [-R] РЕЖИМ ПУТЬ...` | Права в восьмеричном (`640`) или символьном (`u+rw,g=r,o=`) виде; `-R` — рекурсивно |
| `touch [-amc] ПУТЬ...` | Создание пустого файла или обновление времени: `-a` — доступа, `-m` — изменения, `-c` — без создания |
| `exit` | Выход |

VFS не распаковывается на диск. `chmod` и `touch` меняют только память; запись выполняется через `vfs-save`. ZIP сохраняет данные, права и времена файлов. Ошибка `vfs-load` сохраняет прежнюю VFS и текущий каталог. Пути `vfs-load`/`vfs-save` относятся к реальной ОС.

Поддерживаются ZIP Store и Deflate, до 512 МиБ данных и 256 МиБ на файл. ZIP64, многотомные, зашифрованные архивы, ссылки и специальные файлы не поддерживаются. ZIP-примеры автоматически создаются из C++ при сборке в `build/vfs/`; архивы в Git не хранятся.

Все записи принадлежат одному виртуальному владельцу: чтение, обход каталогов и создание файлов проверяют его права. `chmod` поддерживает `ugoa`, `+-=`, `rwxXst`, копирование прав (`g=u`); без указания владельца используется `a`. `touch` сохраняет данные существующих файлов, а без `-a`/`-m` обновляет оба времени. Безопасность реальной ОС этими правами не управляется.

Пути команд относятся к VFS: `/`, `.`, `..`; `~` в `cd` означает корень. Аргументы с пробелами заключаются в кавычки. `tac` и `rev` без файлов или с `-` читают стандартный ввод. `--` завершает разбор флагов. Стартовые скрипты поддерживают `//` и `/* ... */`; переменные `$NAME` и `${NAME}` раскрываются вне одинарных кавычек.

## Примеры запуска

```sh
bash scripts/stage2/run_minimal.sh
bash scripts/stage2/run_nested.sh
bash scripts/stage3/run_all.sh
bash scripts/stage4/run.sh
bash scripts/stage5/run.sh
```

В PowerShell: `./scripts/run_stage.ps1 -Stage 5 -Emulator ./build/emulator.exe` (доступны этапы 2–5). Примеры этапов 4–5 содержат ожидаемые ошибки команд.
Проверки: `cmake -E chdir build ctest --output-on-failure` (для сборки Visual Studio добавьте `-C Debug`).
